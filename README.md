# Swati Parge – Portfolio

Personal portfolio of Swati Parge, Senior Front-End Engineer moving into Cloud & DevOps.

- Static site: HTML, CSS, vanilla JavaScript
- Hosted on Vercel, auto-deployed from this GitHub repo on every push to `main`

## Run locally
Open `index.html` in a browser, or run `npx serve .`
